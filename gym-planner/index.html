    How to export from iPhone

    1. Open the Health app on your iPhone
    2. Tap your profile picture (top right) → Export All Health Data
    3. Share/save the resulting export.zip file to your Mac/PC or a cloud drive
    4. Drop that .zip file below

    Apple does not provide a live web API for HealthKit — connecting a website directly to Health in real time isn't possible on any platform. This import reads your official export file entirely in-browser (via JSZip), so your data never leaves this device.
